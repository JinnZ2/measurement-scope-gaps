# CULTURE_PHYSICS_ANCHOR -- a physics anchor for culture, language and tradition

Co-authored (Kavik + Claude), 2026-10-31 / 2026-11-01. CC0. Markdown only.
Tags per line: OBSERVED / DERIVED / PROPOSED / [stated] / VERIFY (figure or citation not checked
against a primary source) / OWED (gap kept visible).

## Gap

- [stated] (Kavik) No unified physics anchor exists for culture, language and tradition. AIs treat
  cultures either as museum pieces or as deviations unconnected to physics.
- PROPOSED  A practice can be read as an adaptation to physical and environmental constraints first,
  with transmission, institutional framing and labels layered on top. Reading the layers separately
  shows where a label replaced the operation underneath.

## Method: 5-layer decomposition, residual read at each layer (PROPOSED)

```text
1 physics / environment        what the place forces: climate, soil, toxins, energy, pathogens
2 practical adaptation         the operation that handles it
3 transmission                 how the operation is carried (practice, story, rule, kin role)
4 institutional / religious    the frame it is held in
   framing
5 labels                       the words used for it now
residual                       at each layer: what the layer below does NOT explain
```

## Worked examples

- DERIVED   nixtamalization (alkali cooking of maize) makes niacin available; maize-dependent
  populations without it developed pellagra (VERIFY populations and dates)
  layers: 1 maize niacin bound -> 2 alkali process -> 3 recipe -> 4 food tradition -> 5 "cuisine"
- DERIVED   Andean potato system: freeze-drying (chuno), high variety diversity, and eating clay
  with bitter potatoes (VERIFY: clay binding glycoalkaloids, Johns 1986) vs the Irish reliance on
  one variety (Lumper) before the 1845-52 blight (VERIFY)
  residual read: diversity is the physical hedge; a monoculture removes it
- OWED      tomato and lead-pewter story ("tomatoes thought poisonous because acid leached lead
  from pewter plates") -- UNVERIFIED; kept as a candidate, not an example
- PROPOSED  justice forms, coded in this REVISED order (Kavik + Claude):
  ```text
  1 system boundary      individual / state / community / earth
  2 what counts as the loss
  3 what restores balance
  4 THEN punishment form
  ```
  branches kept open:
  - DERIVED   society size as the driver (weakened as a sole explanation)
  - [stated]  (Kavik) centralization as a driver
  - [stated]  (Kavik) migration (Amorite case) as a driver
  - [stated]  (Kavik, oral tradition) accidental killing of a gatherer -> a debt repaid to make the
    tribe whole: the community-boundary example (loss = the tribe's capacity; restoration = making
    it whole; no punishment layer needed)
  - PROPOSED  "eye for an eye" read as a CAP on retaliation; the later monetary reading is a label
    weld (layer 5 changing what layer 2-3 meant). VERIFY against legal-history sources

## Measure / Test

```text
T1  code justice forms in Seshat or the Standard Cross-Cultural Sample (SCCS) with the 4-step order
    above; hold society size constant; does system boundary predict punishment form better than
    size does?
T2  ancestral-state reconstruction of the boundary variable on a language-family tree
    (prior art: Watts et al. 2016, Nature; Mace & Pagel 1994) (VERIFY)
T3  split-timing controls: use independent split dates as natural experiments
    (e.g. Native American ~20-25 ka, Aboriginal Australian ~50-70 ka -- VERIFY ranges)
T4  per worked example: name the layer-1 constraint and test whether removing it (migration,
    trade) is followed by loss or relabelling of the practice
```
